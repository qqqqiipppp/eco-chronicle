# 플로킹 미니게임 교체 및 검증

## 기존 연결 구조

- 기존 팡팡 미니게임은 `js/game.js`의 `pangHTML`부터 `retryPang`까지와 `css/style.css`의 `.pang` 스타일에 정의되어 있었다.
- 내부 몬스터 모드 키 `pang`, `S.modal='pang'`, 임시 런타임 `Pg`, 결과 호스트 `pgResult`, `mountPang`·`pangWin`·`pangLose`·`retryPang` 함수명을 유지했다. 저장 키와 `js/theme-data.js`의 두 `mode: "pang"` 값은 그대로다.
- 관리자 도구의 `admMini('pang')`는 `launchMini()`를 통해 기존 팡팡을 열었다. 일반 관문에서는 `startEncounter()`가 이 모드를 무시하고 턴 전투를 열고 있었으므로, `mode==='pang'`일 때만 `mountPang()`으로 가는 분기를 한 줄 연결했다.
- 성공 결과는 기존과 동일하게 `m.gauge`, `m.gold`, `m.exp`, `rollDrop(m)`을 사용해 정화 게이지·골드·경험치·장비를 지급하고 자동 저장한다. 성공 시 `S.encounterWon`을 설정해야 기존 `nextMonster()`와 `advanceEncounter()`가 다음 관문으로 이어진다. 실패는 기존 `defeatStreak`와 위로 경험치 계산을 유지한다.
- `mode:'turn'`, 다른 미니게임, 탑·멀티플레이·Supabase 코드는 변경하지 않았다.

## 새 플레이

- 이름: **플로킹을 해보자**. 1700×1080 크기의 공원 가장자리 필드를 960×540 캔버스 창으로 따라가며 상하좌우 이동한다. 플레이어는 기존 캐릭터 스프라이트를 재사용한다. 현재 방해 인물 2명은 새 인간형 스프라이트 시트를 사용한다. 상세 변경은 `PLOGGING_NPC_REWORK.md`를 참고한다.
- 기본 쓰레기 42개를 배치한다. 페트병·캔·과자 봉지·비닐봉지·종이·병뚜껑의 6종이며, 모두 1개로 계산한다. 접촉하면 자동 수거되어 사라진다.
- 담배 꽁초를 버리는 아저씨와 일회용 컵을 버리는 아가씨가 각각 순찰하며 약 3.0초·3.4초 간격으로 쓰레기를 버린다. 후반에는 이동과 배출이 약간 빨라진다. NPC 본체에 닿으면 하트가 줄고, 버린 꽁초와 컵은 즉시 안전하게 수거할 수 있다.
- 75초 안에 20개를 수거하면 즉시 성공한다. 시간이 끝나 목표에 못 미치거나 하트가 0이면 실패한다. 기본 하트는 3개이며, 기존 연패 보조에 따라 재도전 시 최대 2개가 추가된다. 충돌 후 0.9초 무적과 작은 밀림이 적용된다.
- 안내 화면에서 `시작하기`를 누르기 전에는 게임 타이머와 애니메이션 루프가 시작하지 않는다. 키보드 방향키/WASD, 화면 드래그, 네 개의 큰 방향 버튼을 지원한다. 결과가 나오면 루프와 입력 리스너를 정리한다.
- 성공 화면은 `플로킹 성공!`, 실제 지급된 보상, 짧은 교육 문구를 보여준다. 실패 화면은 `조금 아쉬워요!`와 수거 개수 및 재도전 버튼을 보여주며, 하트 0에는 별도의 조심 안내를 쓴다.

## 변경 파일

- 수정: `js/game.js`(구 팡팡 구현 제거, 관리자 표시와 관문 안내 문구), `js/encounters.js`(기존 `pang` 관문 진입 연결), `js/theme-data.js`(설명 주석), `index.html`(새 스크립트 로딩), `css/style.css`(플로킹 화면 스타일), `tests/serve-movement.cjs`(로컬 전용 검증 버튼).
- 추가: `js/plogging.js`(새 미니게임), `tests/plogging.test.cjs`(플레이 판정 자동 검사), 이 문서.
- 멀티플레이·Supabase·저장 파일 및 저장 키는 변경하지 않았다. 작업 시작 시 이미 있던 다른 미커밋 변경은 보존했다.
