## 8종의 실제 사용 장소와 변화

모든 구역은 기술을 얻기 전부터 보인다. 미보유 상태에는 막힌 이유와 필요한 조사 방법을 짧게 알린다. 이미 해당 기술 퀘스트를 알고 있다면 실제 기술 이름도 안내한다. **기술 획득만으로는 열리지 않으며, 입구에서 기술을 사용해야 열린다.**

| 기술 / 기존 담당 NPC | 기술 미보유 상태 | 현장 사용 후 변화 | 들어갈 수 있는 공간 / 내부 조사 내용 |
| --- | --- | --- | --- |
| 토양 pH 측정기 / 버섯 박사 | 훼손된 토양의 상태를 몰라 진입 위치를 정하기 어려운 숲 측면 구역 | 조사 제한을 해제하고 진입 경로 표시. 흙 자체를 복구하지 않음 | 숨은 식생 조사 구역 / 식물별 토양 조건, pH·물·빛의 관계 |

| 휴대용 정수기 / 정수장 기사 | 소량의 물 처리가 필요한 샘 주변 조사 제한 구역 | 조사용 물 표현이 바뀌고 인접 구역 출입 허용. 강 전체를 정화하지 않음 | 샘물 생태 조사 구역 / 정수장 4단계와 휴대용 제품의 처리 한계 |

기존 조사 콘텐츠와 구역 이름을 재사용했다. 정수기 안내는 소량의 조사용 물 처리로 제한하며 실제 식수 안전을 보장하지 않는다. 측정기가 오염을 제거하거나 열화상카메라가 벽을 없애는 표현은 넣지 않았다.

## 실제 위치와 맵 보호

기존 월드의 경로·출발점·오브젝트·NPC·충돌 데이터를 이용해 지역 진입 시 결정적으로 배치한다. 기본 크기는 240×220이며 도시·대기의 밀집 구역은 200×190으로 줄여 기존 충돌 오브젝트를 피한다. 더 작은 180×180 후보도 안전 배치의 대안으로만 준비했다.

최종 브라우저 검증에서 확인한 월드 좌표는 다음과 같다. 좌표는 화면 좌표가 아닌 현재 확장된 월드의 좌표다.

| 기술 | 구역 좌상단 / 크기 | 외부 사용 표지 | 내부 추가 조사 표지 |
| --- | --- | --- | --- |
| soil | (2350, 280), 240×220 | (2470, 522) | (2513, 390) |
| water | (630, 600), 240×220 | (750, 842) | (793, 710) |
| sorbent | (2390, 1440), 240×220 | (2510, 1682) | (2553, 1550) |
| generator | (2350, 880), 200×190 | (2450, 1092) | (2486, 975) |
| dust | (2270, 160), 200×190 | (2370, 372) | (2406, 255) |
| solar | (2390, 1400), 240×220 | (2510, 1642) | (2553, 1510) |
| filter | (110, 1080), 240×220 | (230, 1322) | (273, 1190) |
| thermal | (550, 720), 240×220 | (670, 962) | (713, 830) |

배치 검사는 기존 메인 경로의 표본에서 75px, 출발점에서 160px, 주요 오브젝트 반경에서 추가 100px, NPC의 기준 위치에서 180px의 여유를 둔다. 기존 충돌 오브젝트와 남쪽 입구의 접근 공간도 검사한다. 기존 메인 오브젝트와 경로 데이터는 제거하지 않는다.

구역과 짧은 접근 공간을 덮는 **충돌 없는 배경 장식만 화면에서 숨긴다**. 최종 배치의 장식 기록 수는 soil 14, water 5, sorbent 2, generator 1, dust 4, solar 4, filter 8, thermal 9였다. 이 수에는 작은 꽃·갈대 같은 장식도 포함되며 모두 나무를 뜻하지 않는다. 원본 에셋 파일을 삭제하지 않았다.

후반에 등장하는 기존 인물의 위치를 미리 예약해 진행 상태에 따라 구역 위치가 바뀌지 않게 했다. 이 예약 주변의 일부 장식 배치는 이전과 달라질 수 있다. 기술 사용 자체는 기존 충돌 오브젝트 목록이나 주요 경로를 바꾸지 않는다.

## 충돌과 저장 상태

- `ecoTechUnlocked`: 기존대로 기술 보유 여부.
- `ecoTechQuests`: 기존 퀘스트 수락·조사·정수 순서 상태.
- `ecoTechSites`: 현장에서 사용한 기술 ID. **장벽 개방의 유일한 저장 기준**.
- `ecoTechFindings`: 열린 구역 내부에서 기존 추가 조사 콘텐츠를 확인한 ID.

새 저장 필드, 세이브 키, 저장 버전은 추가하지 않았다. 기존 정규화와 저장/불러오기 코드를 그대로 사용한다. 이전 저장에 이미 기록된 `ecoTechSites`도 해당 구역을 열린 상태로 복원한다.

닫힌 구역은 내부 전체를 막는 사각형 하나로 처리한다. 열린 구역은 북·동·서 벽과 남쪽 양옆만 유지하고 중앙 입구를 비운다. 캐시한 숫자 사각형을 기존 이동 함수에서 검사하므로 DOM 검색이나 네트워크 응답이 필요하지 않다.

기존 저장 위치가 새 장벽 안에 겹치는 경우 그 장벽에서 빠져나갈 수 있게 처리했다. 바깥으로 나온 뒤에는 닫힌 구역에 다시 들어갈 수 없다. 추가 조사 상호작용은 열린 구역의 실제 내부에 서 있을 때만 허용하므로 벽 바깥에서 표지만 가까이 읽는 우회도 막는다.

기존 퀘스트용 조사 지점은 메인 동선에 유지했다. 기술 사용 지점은 새 구역 남쪽 외부, 추가 조사 지점은 내부로 옮겼으며 기존 표지 키·기술 ID·보상 기록을 재사용한다.

## 실제 브라우저 플레이 검증

환경: Windows 데스크톱의 Codex 내장 Chromium 브라우저, 1280×800, 로컬 정적 테스트 서버. 테스트 저장 번호 `EC9900`을 사용해 기존 사용자 저장과 분리했다.

로컬 테스트 도구는 각 구역 **바깥 접근 지점**에 시작 위치를 놓고 기존 퀘스트 함수로 퀴즈·조사 완료를 진행했다. 입구 통과 검증에서는 테스트 도구가 기존 입력을 유지하고 **실제 게임의 requestAnimationFrame → tick → 충돌 → 캐릭터 렌더링**을 실행했다. 열린 내부로 순간이동시켜 성공으로 판단하지 않았다. 퀘스트 완료 절차 일부는 테스트 도구가 자동 진행했으며 학생의 전체 수동 플레이 시간을 측정한 것은 아니다.

여기서 '통과'는 해당 검증의 성공을 뜻한다. 첫 두 열에서는 실제 이동이 장벽에 막히는 것을 확인했다. 새로고침 후 8종 모두 저장된 개방 상태에서 다시 실제 입구를 걸어 통과했다.

기존 기능도 실제 화면에서 확인했다.

- 기존 관리자 전투 진입, 기술 목록 표시, 기본 공격 실행.
- `플로킹을 해보자` 진입과 시작. 기존 28개 목표·75초·하트·NPC 6명 구조 유지.

- 지도 메뉴의 6개 지역 표시와 지역 이동·복귀.
- 기존 NPC 퀘스트 함수와 생태기술 획득, 저장·불러오기·새로고침.

새로운 처리되지 않은 JavaScript 예외는 0개였다. 테스트 서버는 Supabase CDN을 의도적으로 제외하므로 기존의 CDN 사용 불가 콘솔 메시지는 발생한다. 이를 새 오류로 집계하거나 콘솔 전체가 무경고라고 주장하지 않는다. 실제 Supabase 다중 브라우저 접속은 이번 작업에서 다시 수행하지 않았다.

## 발견 문제와 최소 수정

1. 도시의 장식·시설 밀도로 240×220 구역을 안전하게 배치하지 못하는 경우가 있었다. 기존 충돌 오브젝트를 옮기는 대신 더 작은 구역 후보를 추가했다.
2. 후반 인물이 나타나면 열화상 조사 구역 위치가 달라질 수 있었다. 기존 인물의 미래 위치를 같은 배치 함수로 예측해 먼저 예약했다. 후반 진행 전후 위치 일치 테스트를 추가했다.
3. 벽 바깥에서도 내부 표지와 가까워질 수 있으므로 실제 열린 내부에 서 있어야 조사할 수 있도록 조건을 강화했다.
4. 이전 저장 위치와 신규 장벽이 겹칠 가능성에는 기존 위치에서 탈출을 허용하는 충돌 처리를 넣었다.

## 성능과 실제 기기 한계

새로운 game loop, 지속 애니메이션, 폴링·재연결 타이머, 네트워크 메시지, 래스터 이미지 에셋은 추가하지 않았다. 최대 2개 구역의 데이터는 지역 진입 시 계산하고, 열린 구역 두 개를 합쳐도 추가 충돌 사각형은 최대 10개다. 이동 중에는 숫자 비교만 수행한다. 장식 DOM 조회는 월드 생성 시에만 한다.

구역 표현은 작은 정적 inline SVG이며 기름막 감소에만 한 번의 0.5초 CSS 애니메이션을 쓴다. 동작 줄이기 설정에서는 이를 끈다. 기존 근접 상호작용과 모달을 재사용한다.

최종 새로고침 검증에서 측정한 구역 배치 시간은 데스크톱 브라우저의 단회 표본 기준 **2.7–10.8ms**였다. 평균 FPS나 장기 프레임 분포를 측정한 수치가 아니며, Galaxy Tab S5e의 측정값도 아니다.

Galaxy Tab S5e에서는 지역 진입 시의 작은 계산과 정적 구역 DOM이 추가되지만, 이동 중 작업량은 제한되어 있어 지속 렌더링 부담은 작을 것으로 예상한다. **Tab S5e 실기기 및 학교 Wi-Fi 환경은 이번 작업에서 시험하지 않았다.**

## 최종 결과

8종 모두 기존 지역 안의 선택형 공간에서 실제 진입 차단과 현장 사용 후 개방이 동작한다. 내부의 기존 교육 콘텐츠와 저장 기록을 재사용하며, 메인 스토리는 기술 미보유 상태에서도 기존 경로로 진행할 수 있다. 장비 개편·기존 퀘스트·멀티플레이·전투·다른 미니게임 로직은 이번 작업 범위에서 유지했다.
