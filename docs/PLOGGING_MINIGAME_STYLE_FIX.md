# 플로킹 미니게임 시각 스타일 정리

## 기존 본편 스타일 특징

- 본편 월드는 테마별로 그린 반복 배경(`ECO_ART`) 위에 굽은 흙길과 나무·바위·버섯·울타리 등의 환경 스프라이트를 배치한다. 윤곽, 명암, 바닥 그림자가 있는 따뜻한 색감이다.
- 플레이어와 사람형 NPC는 몸통 걷기 시트와 머리 레이어를 조합한다. 본편 NPC는 `npcTint`로 피부·머리 색을 적용한다.
- HUD와 대화창은 어두운 보라색 패널, 크림색 본문, 금색 제목·버튼을 쓴다. 전투·다른 미니게임 결과창도 같은 `sheet`, `mhead`, `btn` 체계를 쓴다.

## 기존 문제점과 수정 방법

| 기존 문제 | 수정 |
| --- | --- |
| 짙은 단색 바닥, 직선 사각형 길과 몇 개의 사각형 나무가 본편 월드와 달랐음 | 본편 `ECO_ART` 배경과 `ecoScenerySource` 환경 스프라이트를 사용하고, 흙길에 곡선 가장자리·발자국색 변화를 적용 |
| 페트병·캔·봉지·종이 등이 작은 사각형 기호처럼 보였음 | 8종을 각각 실루엣, 어두운 윤곽선, 색면, 반사광·접힘·라벨 등으로 재작화. 바닥 접지 그림자 추가 |
| 방해 인물은 상자 몸통과 네모 얼굴로 만든 임시 그림이었음 | 본편의 `body_*` 걷기 시트, `head_*` 머리, `npcTint`를 사용. 담배·커피컵 소품과 본편식 이름표 추가 |
| 시작창·HUD·조작 버튼이 녹색 HTML 상자처럼 튀었음 | 본편 CSS 변수와 패널·버튼 색감, 둥근 카드 여백으로 통일 |

## 변경 파일과 에셋

- `js/plogging.js`: 화면 그리기 관련 함수와 일시적 이미지 캐시만 수정. 수거 목표, 시간, 이동 속도, 하트, NPC 충돌·투기, 보상·저장 흐름은 유지.
- `css/style.css`: 플로킹 화면의 HUD·시작창·버튼·알림 색상과 테두리만 수정.
- 새 이미지 파일 없음. 새 Base64 없음. 기존 테마 배경, 환경 오브젝트, 캐릭터 몸통·머리 스프라이트를 재사용.

## 쓰레기·NPC·필드·UI

- 쓰레기: 페트병(뚜껑·라벨·투명 반사), 캔(금속 림·컬러 라벨), 과자 봉지(양끝 포장 주름), 비닐봉지(손잡이·반투명 주름), 종이(접힌 모서리·줄), 병뚜껑(둥근 림), 담배꽁초(필터), 커피컵(뚜껑·컵 슬리브). 작은 캔버스에 종류별로 한 번만 그려서 재사용한다.
- 방해 NPC: 두 인물 모두 기존 9프레임 몸통과 머리 레이어를 사용하며 기존 방향값(south/north/west/east)에 따라 방향을 바꾼다. NPC 이동·충돌 로직은 변경하지 않았다.
- 필드: 현재 테마·정화 상태의 본편 배경을 반복해서 사용하고, 기존 나무·덤불·바위·꽃·울타리 등 30개 장식물을 배치했다. 장식물은 충돌에 참여하지 않는다.
- UI: 본편의 `--panel`, `--gold`, `--cream`, `--line` 색과 기존 결과창 스타일에 맞췄다. 터치 방향 버튼 크기와 모바일 축소 규칙은 유지했다.

## 검증 결과

- 관리자 모드에서 **플로킹 단독 실행**: 숲 정화 완료 배경으로 진입·시작, 본편 플레이어/NPC와 환경 자산을 나란히 비교했다. 쓰레기 종류·두 인물 소품·이름표·HUD 판독을 확인했다.
- **일반 게임 흐름**: 강의 기존 `pang` 관문에서 `플로킹 시작` → 수거 완료 → 정화 게이지 +5%, 골드 +19, 경험치 +24 → `계속하기` → 다음 관문 표시를 확인했다. 이 수치는 로컬 시험 상태의 보상이다.
- `node --check js/plogging.js` 통과. `tests/plogging.test.cjs`, `tests/movement.test.cjs`, `tests/presence35.test.cjs` 모두 통과.
- 로컬 브라우저 미니게임 JavaScript 오류 없음. CDN 로드를 의도적으로 제외한 시험 URL에서는 기존 Supabase 연결 실패 로그만 발생했고 개인 게임 진행은 계속됐다.

## 성능 영향과 한계

- 정적 배경과 길은 테마당 1700×1080 화면 밖 캔버스에 한 번 합성한 뒤 현재 화면 영역만 복사한다. 쓰레기 8종도 작은 캔버스에 한 번 그려 재사용한다. 새 애니메이션·DOM 노드·고해상도 이미지 파일은 추가하지 않았다.
- 로컬 브라우저 시험에서 화면은 정상적으로 움직였으나 **Samsung Galaxy Tab S5e 실기기 FPS·발열은 측정하지 못했다**. 수업 전 기기에서 75초 한 판을 직접 돌려 확인하면 좋다.
