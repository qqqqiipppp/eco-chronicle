# 학생 실사용 전 문구·제목·관리자 표시 정리

2026-09-30 검증. 이번 실행은 학생에게 보이는 문구와 제목, 개발 정보의 표시 범위만 수정했다. 시작 화면의 기존 그래픽과 레이아웃은 유지했다.

## 학생 화면 텍스트 점검

| 화면 | 학생 플레이에 필요한 정보(A) | 관리자 전용 정보(B) |
|---|---|---|
| 시작·새 게임 | 제목, 한 문장 목적, 이름·외형·정령 선택, 저장 불러오기 | 빌드 번호 |
| 월드·HUD·지도·가방·장비·퀘스트·생태기술 | 체력, 골드, 현재 진행, 아이템 효과와 다음 행동 | 빌드, 내부 저장 키, 서버·채널 이름 |
| NPC·전투·미니게임 | 대사, 퀴즈, 목표, 보상, 조작에 필요한 안내 | 디버그 수치 |
| 저장·멀티플레이 | EC 번호, 저장 실패, 접속한 친구, 온라인 사용 불가 안내 | 연결 상태 세부값, Presence/Broadcast 상태, 내부 playerId |

코드 전체에서 build/version/offline/channel/Supabase/Presence/Broadcast/playerId/debug 계열을 검색하고 학생 DOM으로 이어지는 표시 경로를 확인했다. 내부 코드·콘솔·관리자 모드에 남은 문자열은 학생 화면 텍스트와 구분했다.

## 변경 내용

- 시작 화면, 브라우저 제목, 초기 로딩 화면, 수료증의 게임 이름을 `환경 원정대`로 통일했다. 학생 화면의 영문 부제와 빌드 문구를 제거했다.
- 시작 설명은 `6개 지역을 탐험하며 환경 문제를 해결해 보세요.` 한 문장으로 줄였다. 이름·외형·정령·첫 안내 화면도 다음 행동 중심으로 정리했다.
- 정령 선택 카드에는 이름, 고유 기술, 실제 전투 효과만 남겼다. 효과 데이터와 기술 ID는 변경하지 않았다.
- 6개 지역 NPC 60명의 `talk` 대사를 역할에 맞는 짧은 대화로 수정하고, 6개 아이템 요청 문구를 다듬었다. 예: 수질 검사원은 눈으로만 물 상태를 알기 어렵다고 말하며 측정을 권하고, 해변 청소부는 모래 속 쓰레기를 함께 찾자고 제안한다.
- NPC 대화를 가리던 학습 데이터의 `talk` 덮어쓰기를 제거했다. 학습 내용과 퀴즈는 기존 학습 화면과 퀴즈 데이터에 남는다. 퀴즈 조건·정답·보상·NPC ID는 변경하지 않았다.
- 일반 NPC 대화에 짧은 대사를 처음 표시한다. 겨루기를 청하는 NPC도 고유 대사를 먼저 말한다.
- 일반 대사에서 갑자기 등장하던 기념일, 연도, 퍼센트와 긴 통계를 덜어냈다. 학습·퀴즈 콘텐츠의 사실 설명은 유지했다.
- 생태기술 퀘스트 중에는 조사 개수와 다음 행동을 보여 주고, 긴 교육 설명은 기술을 획득했을 때와 조사 지점에 남겼다. 퀘스트 목표와 보상은 변경하지 않았다.
- 플로킹 시작 문구는 목표 수량·시간·충돌 규칙으로, 다른 두 미니게임의 시작 문구는 필수 조작으로 줄였다.
- 저장 완료 문구를 EC 번호와 같은 태블릿에서 이어할 수 있다는 안내로 축약했다. 저장할 수 없을 때는 선생님께 알리도록 안내한다.
- 일반 시작 화면과 농장 HUD에서 빌드 표시를 제거했다. 멀티플레이 기술 상태 패널은 관리자 모드에서만 보인다. 관리자 도구에는 빌드, 지역, 저장 코드, Supabase 상태, 채널, 연결 상태와 접속·재연결 수를 표시한다.
- 접속인원 화면에서 연결 불가 시 `온라인 기능을 사용할 수 없어요. 게임은 계속할 수 있어요.`로 안내한다. 게임 진행은 계속된다.
- 초기 로딩 실패 시 학생에게는 짧은 오류 안내를 보이고, 세부 오류는 브라우저 콘솔에 남긴다.

## 유지한 호환 구조

`echo:` 저장 접두어, `echo:__index`, `echo:__last`, ECxxxx 번호, 저장 버전, 마이그레이션, 상태 필드, 장비·생태기술·NPC·지역 ID, 퀘스트 조건, 멀티플레이 채널·동기화 로직은 변경하지 않았다. NPC 데이터 비교에서 ID·조건·보상 등 `talk`와 일부 `ask`를 제외한 필드가 원본과 동일함을 확인했다.
