기존 NPC의 원래 이야기·퀴즈·선행 조건·보상을 마친 뒤 추가 생태기술 버튼이 나타납니다. 7종은 실제 월드의 서로 다른 조사 표지 3곳을 방문하고 NPC에게 보고합니다. 정수기는 응집 → 침전 → 여과 → 소독 순서 퀴즈를 맞힌 뒤 보고합니다. 잘못된 순서는 다시 시도할 수 있습니다. 기존 퀘스트를 덮어쓰지 않습니다.

사용 장소에서 기술이 없으면 필요한 기술과 NPC를 안내합니다. 획득 후 사용하면 새 조사 표지가 월드에 나타나고, 그 위치에서 실제 추가 조사와 교육 설명을 열 수 있습니다. 구현한 개방은 **새 월드 조사 상호작용의 잠금 해제**입니다. 기존 지형·충돌이나 원래 통행로를 변경하거나 신규 맵을 만든 것은 아닙니다.

표지는 기존 경로에서 장애물·기존 상호작용·NPC와 거리를 두고 배치합니다. 실제 맵 기준 숲 5개, 강 7개, 바다 5개, 도시 5개, 대기 5개, 기후 10개가 배치되었습니다. 조건에 맞는 표지만 표시되며 최대 10개 후보의 근접 검사를 기존 루프에서 수행합니다. 별도 타이머/애니메이션 루프를 추가하지 않았습니다.

## 저장과 호환

- ecoTechUnlocked: 영구 획득한 기술 ID 배열.
- ecoTechQuests: 기술별 accepted / surveyed / orderDone.
- ecoTechSites: 기술 사용으로 개방한 지점 ID 배열.

4개 필드는 지역별 THEME_FIELDS와 분리해 지역 이동 후 유지됩니다. 구형 저장에는 빈 배열/객체를 채우고, 알 수 없는 ID·중복 조사·잘못된 인덱스를 정리합니다. 획득/조사/개방 시 기존 autosave를 사용합니다. 세이브 키와 저장 버전은 변경하지 않았습니다. 기술을 장비 슬롯/owned에 넣지 않으며 능력치나 전투 보상을 추가하지 않습니다.

기존 migrate가 일반 장비 목록만 검사해 전설 장비를 제거할 수 있는 문제를 발견했습니다. 기존 gearFind/gearList로 유효성을 검사하도록 최소 수정해 전설 보유 및 장착도 보존합니다. 정상적인 기존 장비 ID와 보유 상태는 유지됩니다.

## 발견 및 수정한 오류

1. 구형 저장 검사에서 전설 장비가 제거될 수 있던 문제: 일반+전설 조회를 재사용해 보존.

3. 기술 미보유 안내의 조사(이/가)를 기존 J 함수로 교정.
4. 테스트 도구의 지역 전환 시 월드 재생성이 누락된 문제: 테스트 도구에서 월드 재생성을 수행하도록 수정. 실제 게임의 enterTheme 로직은 변경하지 않음.
