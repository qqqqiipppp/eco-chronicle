# 저장 호환성

SAVE_VERSION=8 및 echo:계정코드, echo:__index, echo:__last, eco_mute 키를 유지했습니다. 저장 점검 임시 키 echo:__t도 원본과 같습니다. 몬스터·아이템·스테이지 ID 및 저장 객체 구조를 변경하지 않았습니다.

동일 브라우저와 동일 HTTP(S) origin(프로토콜·호스트·포트)에서 원본의 저장을 분리본으로 불러오는 검증을 통과했습니다. 장비·골드·경험치·진행 중 미니게임이 유지됐고 새로고침 후 다시 불러오기도 통과했습니다.

기존 file: 게임과 새 https: 사이트는 저장 공간이 다릅니다. 키가 같아도 자동으로 이전되지는 않습니다. 원래 게임 파일과 브라우저 프로필을 보관하세요. 제공하는 원본 백업은 프로그램 백업이며 사용자 기기의 플레이 기록이 들어 있지 않습니다.

새 주소로 기록을 옮기려면 기존 게임을 실행하던 브라우저에서 해당 게임의 저장 값을 별도로 내보내고 새 주소로 가져오는 절차가 필요합니다. 이번 작업에서는 요청대로 저장 UI나 가져오기 기능을 추가하지 않았습니다.

고정 웹 주소로 배포한 뒤에는 origin과 키를 유지해야 저장이 이어집니다. 다른 기기/브라우저로 바꾸거나 사이트 데이터를 지우면 저장은 이어지지 않을 수 있습니다. 같은 GitHub 사용자 도메인의 다른 게임과 키가 겹칠 가능성도 있으나, 이번에는 요청대로 키를 임의 변경하지 않았습니다.

참고: https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage
