# 현재 접속자 메뉴 작업 기록

## 변경 범위

- 신규: `js/player-list.js`, `css/online-players.css`
- 수정: `index.html`, `js/presence.js`
- 로컬 다중 접속 시험용 변경: `tests/serve-movement.cjs`
- `js/movement.js`, `js/remote-players.js`, `js/game.js`, 저장 키와 게임 데이터는 변경하지 않았다.

월드 HUD에 `접속자` 버튼을 추가했다. 기존 모달 열기/닫기 흐름으로 현재 테마의 접속자 표를 보여 준다. 자기 자신을 맨 위에 놓고, 나머지는 레벨 내림차순과 닉네임 순으로 정렬한다. 표 내부에 스크롤과 고정 헤더를 적용하고, 좁은 화면에서는 글자 크기와 칸 간격을 줄였다. 정보가 없으면 `온라인 정보 없음`, 연결할 수 없으면 `연결할 수 없습니다`를 표시한다. 정령 아이콘은 테마별/단계별 이미지 매핑을 별도로 만들 필요가 있어 이 단계에서는 텍스트로 표시했다.

## 공유 정보와 출처

Presence의 기존 `playerId`, `nickname`, `theme`, `joinedAt` 및 외형 필드는 유지했다. 접속자 표용으로 아래 네 필드만 Presence 메타데이터에 추가했다. 다른 브라우저에서 받은 값은 길이와 형식을 제한하고 텍스트로만 출력한다.

| 필드 | 게임 상태의 출처 | 표시 방법 |
| --- | --- | --- |
| `spirit` | `S.petKey`, `S.petStage`와 기존 `petName()` | 현재 정령의 실제 단계별 이름 |
| `level` | `S.lv` | `Lv. n` |
| `equipment` | `S.gear`와 기존 `gearFind()` | 무기, 갑옷, 투구, 신발 순 첫 장착 장비의 실제 이름; 없으면 `없음` |
| `progress` | `S.themeId`, `S.monIdx`, `S.cleared`와 기존 `THEMES`의 이름/몬스터 정보 | 현재 테마의 단계, 보스 또는 정화 완료 |

기존 `presence.js`의 500ms 상태 점검에서 닉네임, 외형 또는 이 요약 값이 달라졌을 때만 `track()`으로 다시 게시한다. 매 프레임 게시하지 않는다. 레벨·장비·정령·단계 변경을 위한 게임 로직 후킹은 없다. Movement Broadcast의 `playerId`, `theme`, `joinedAt`, `seq`, `x`, `y`, `direction`, `moving` 형식과 송신 코드는 변경하지 않았다.

## 실제 브라우저 시험

로컬 서버에서 독립 브라우저 탭 A/B/C 세 개를 동시에 숲에 접속시켜 각 탭의 접속자 3명, 자기 자신 `(나)`, 닉네임 및 서로 다른 게임 상태를 확인했다. 초기 시험 상태는 A `조약돌 정령 / Lv.5 / 없음 / 숲 1단계`, B `물방울 정령 / Lv.6 / 단검 / 숲 2단계`, C `불씨 정령 / Lv.4 / 사슬 갑옷 / 숲 3단계`였다.

| 상황 | 관찰 결과 |
| --- | --- |
| B 레벨 상승 | A/B/C에서 B가 `Lv.7`로 갱신 |
| B 무기 변경 | A/B/C에서 B 장비가 `창`으로 갱신 |
| B 진행 단계 변경 | A/B/C에서 B가 `숲 3단계`로 갱신 |
| A 정령 변경 | A/B에서 A가 `물방울 정령`으로 갱신 |
| B 강으로 이동 | A/C 숲 목록에서 B 제거; B의 강 목록에는 B만 표시 (`강 1단계`) |
| B 숲 복귀 | A/C 목록에 B가 다시 나타나며 변경된 요약 정보 유지 |
| C 탭 종료 | A/B 목록에서 C 제거; 원격 캐릭터 수도 감소 |
| 기존 이동 동기화 | B 이동 후 A에서 B 원격 캐릭터 좌표 갱신 확인 |
| 기존 메뉴 | 접속자 창 닫기, 가방, 지도 열기 및 월드 복귀 정상 |
| 기존 저장/불러오기 | 저장 후 시작 화면의 이어하기로 레벨·체력·골드 및 월드 복구 확인 |
| Supabase 불가 | CDN을 제외한 시험 탭의 목록에 `연결할 수 없습니다` 표시, 로컬 이동 정상 |

3개 탭 시험 중 JavaScript 오류는 관찰되지 않았다. 모바일 전용 스타일과 20~30명용 내부 스크롤은 적용했지만 실제 작은 기기/대규모 접속 시험은 수행하지 않았다. 전투와 미니게임은 이번 변경에서 실행 시험하지 않았다.
