# 배포 버전과 캐시 갱신

배포 버전의 원본은 `js/build-version.js`의 `BUILD_VERSION`입니다. 세이브 구조 버전과 별개이며 학생 저장 키나 진행도에 영향을 주지 않습니다.

수정본을 배포하기 전에 다음 명령으로 새 버전을 지정합니다.

```text
node tools/update-build-version.cjs 2026.10.07.2
```

이 작은 관리 도구는 HTML의 로컬 CSS/JS 주소와 CSS의 모닥불 이미지 주소에 같은 `?v=` 값을 반영합니다. 현재 원본 버전을 다시 적용하려면 인자 없이 실행합니다. 게임 실행이나 GitHub Pages에는 Node.js 또는 빌드 과정이 필요하지 않습니다.

게임 이미지 사전은 기존 덮어쓰기가 완료된 뒤, 첫 렌더 전에 `ecoVersionAssets`로 한 번 처리합니다. 이후 로딩되는 플로킹 이미지 사전도 한 번 처리합니다. 직접 만든 생태기술·탐험 장소·제목 이미지 주소는 `ecoAssetUrl`을 사용합니다. 파일명과 실제 폴더 구조는 유지되며 외부/CDN, `data:`, `blob:` 주소는 바뀌지 않습니다.

새 이미지 사전을 추가할 때는 `index.html`의 명시적인 처리 목록에 포함합니다. 직접 이미지 주소를 만드는 경우에는 `ecoAssetUrl`로 감쌉니다. 서비스워커는 추가하지 않습니다.

새 배포의 HTML을 읽은 뒤에는 버전이 달라진 CSS/JS/이미지가 별도 캐시 주소로 요청됩니다. 이미 열려 있던 페이지나 오래된 HTML 자체가 계속 사용되는 상황은 새 HTML을 받아 새로고침해야 반영됩니다. 캐시 검증 시 HTML 문자만 확인하지 말고 브라우저의 실제 요청 주소와 최신 응답 내용도 확인합니다.
