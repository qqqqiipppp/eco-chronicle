# 플로킹 방해 NPC 재작업

## 변경 범위

- 새 에셋: `assets/images/characters/plogging_smoker_sheet.png` (1235×1274, 1,250,039바이트), `assets/images/characters/plogging_coffee_sheet.png` (1216×1294, 1,294,819바이트).
- 게임 코드: `js/plogging.js`의 두 NPC 그림, 순찰, 버리기 동작과 충돌 판정만 변경했다. 기존 전투, 보상, 저장 키, 멀티플레이 코드는 변경하지 않았다.
- 검증 코드: `tests/plogging.test.cjs`에 두 NPC 접촉, 무적, 쓰레기 수거 검사를 추가했다. `tests/serve-movement.cjs`에는 브라우저에서 NPC를 나란히 세우고 충돌·버리기·수거를 재현하는 로컬 시험 버튼을 추가했다. 이 버튼은 실제 게임의 `index.html`에는 포함되지 않는다.

## 이미지와 모션

두 에셋은 본편의 인간형 캐릭터 이미지를 화풍 참고로 사용해 새로 생성한 투명 PNG 시트다. 아저씨는 희끗한 짧은 머리·남색 재킷·담배꽁초, 아가씨는 묶은 갈색 머리·산호색 상의·청록색 치마·일회용 컵으로 구분된다. 두 파일은 동일 그림의 색만 바꾼 것이 아니다.

각 시트는 **가로 4열 × 세로 3행**이다. 열은 아래·위·왼쪽·오른쪽, 행은 대기·걷기·버리기다. 게임은 기존 `Pg` 애니메이션 프레임에서 약 170ms마다 걷기 행을 전환한다. 버리기 시작 후 170~650ms에는 버리기 행을 표시한다. 각 NPC는 자신의 시트에서만 프레임을 선택한다.

아저씨와 아가씨는 별도 속도·방향·배출 주기를 갖고 필드를 순찰한다. 방향은 현재 속도에서 정하고, 가끔 작은 각도로 바꾸며 필드 경계에서 되돌아간다. 플레이어를 추적하지 않는다. 버릴 시간이 되면 약 760ms 멈추고, 동작 시작 약 330ms 뒤 손과 발 근처에 각각 꽁초 또는 컵을 생성한 뒤 다시 걷는다. 새 타이머나 애니메이션 루프는 만들지 않았다.

## 충돌과 수거

NPC 접촉은 플레이어 발 위치와 NPC 발 위치를 기준으로 가로 21, 세로 15의 타원형 판정을 사용한다. 본체 접촉 1회에 하트 1개가 줄고 HUD가 즉시 갱신된다. 900ms 동안 추가 피해를 막고 플레이어를 조금 밀어내며 깜빡임과 짧은 안내 문구를 보여 준다. 아저씨·아가씨 모두 같은 보호 규칙을 쓴다.

꽁초와 컵은 일반 쓰레기 목록에만 추가한다. 닿으면 즉시 수거 수가 올라 목표에 반영되고 하트는 줄지 않는다. 쓰레기에 대한 이전 위험 시간 판정은 사용하지 않는다.

로컬 브라우저 검사는 Supabase CDN을 일부러 제외한 격리 서버에서 수행했다. 이 환경의 연결 불가 표시는 예상된 상태다. 관리자 모드에서 남은 브라우저 충돌·수거 확인과 실제 태블릿 성능 확인은 별도 실기기 검증이 필요하다.

## 제작 기록

두 PNG는 내장 `imagegen`으로 새로 생성했다. 참고 자료는 프로젝트의 기존 인간형 캐릭터 이미지와 `js/visuals.js`의 몸통 이미지이며, 기존 에셋을 덮어쓰지 않았다. 제작 지시는 각각 중년 남성/젊은 여성의 의상·소품을 구별하고, 투명 배경에 4방향 × 대기·걷기·버리기 3행을 배치하며, Eco Chronicle의 부드러운 도트 밀도와 윤곽선에 맞추라는 내용이었다.
